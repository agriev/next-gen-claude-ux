# WS-07 — AI-native interfaces & reasoning trace UIs

**Scope:** How current AI tools represent LLM reasoning processes — chain-of-thought, tool-call sequences, multi-agent coordination, and the resulting artifacts (file edits, generated UI, citations). Focus on **what visual surface the reasoning lives on** and **how that surface scales** when there are multiple agents, multiple tool calls, branches, retries, or errors. Excludes pure prompt-engineering IDEs without runtime trace surfaces.
**Date:** 2026-05-23
**Sources consulted:** 20 primary + 8 supporting

---

## Lens pass

### L1 — Spatial primitives

The catalog separates into **four spatial families**:

1. **Linear-list (1D)** — chat transcripts with embedded "thinking" sections (ChatGPT o3, Claude chat, Perplexity, Replit chat). Primitive = message; thoughts/tools are nested message-types.
2. **Tree (1.5D)** — hierarchical trace views with parent → child runs (LangSmith, Langfuse, Phoenix, Helicone, Weave). Primitives = {trace-root, span, leaf-call}; edges implicit (indentation).
3. **Multi-pane grid (2D layout, 1D contents)** — Cursor Agents Window, Devin's chat+editor+browser+terminal, Bolt/v0/Lovable two-pane, Claude Artifacts split-screen. Primitives = {chat-tile, code-tile, browser-tile, terminal-tile, preview-tile, plan-tile}.
4. **Node-graph (true 2D)** — ComfyUI, LangFlow, Flowise, Dify, CrewAI flow plot, AutoGen Studio. Primitives = {node, edge, typed port, collapsed subgraph, comment}. Position is meaningful, but only as an *authoring* surface. ComfyUI partially blurs this: the running graph reuses authoring positions, a green border traveling node-to-node as execution progresses.

**No tool ships a 3D reasoning surface.** Multi-pane workspaces use 2D screen real estate but do not give individual reasoning steps spatial coordinates.

### L2 — Data → form mapping

Same data classes appear across most tools; the **encoding** differs sharply.

| Data class | LangSmith / Langfuse / Phoenix | Claude chat / o3 | Cursor / Devin / Copilot Workspace | ComfyUI / LangFlow |
|---|---|---|---|---|
| Thinking text | nested span labeled `LLM` or `chain.invoke` | collapsible "Thinking" block above reply | streaming text in chat tile | absent (graphs are authored, not reasoned) |
| Tool call | child span with name = tool name, IO in side panel | tool-use card with name, params, result | tool-use card or terminal line | node with input/output sockets |
| File diff | text in IO panel (not rendered as diff) | rare; Artifacts re-renders whole file | rich syntax-highlighted diff per file, per-hunk accept | N/A |
| Sub-agent spawn | new child span branch; same tree | rare; visible as a tool call to `Task` | new tile/tab in Agents Window (Cursor 3+) | sub-graph node (collapsible) |
| Cost (USD) | per-span and trace-total, prominent | hidden (consumer UI) | per-agent total in Agents Window header | absent (compute is local GPU) |
| Tokens in/out | per-span numbers | hidden | rarely shown | absent |
| Wall-clock duration | flame-graph bars (Langfuse) or per-span ms | "Thought for N seconds" pill | per-step timestamps in chat | progress dot per node |
| Error / retry | red span, exception in IO; retries are siblings or new traces | inline red banner "Tool errored" | red border on the file tile or step in plan | red border around failed node |
| Branch / alternative | not first-class — multiple traces are a list | not modeled (linear) | not modeled (the chat is linear) | not modeled (DAG, not search) |
| User input mid-run | special span type "Human" | inline as a new user message | inline approval prompt (Composer) | absent |

Note the consistent failure mode: **branches and alternatives are not represented** anywhere in the catalog. Even when an agent backtracks (retries with a different approach), the trace tree just appends, losing the "we tried X, it failed, so we tried Y" structure. The closest hint is the OpenAI o3 thinking summary which sometimes verbalizes "Let me try a different approach…", but the prior approach is not visually preserved.

### L3 — Camera & navigation

Most tools are *scroll*; only ComfyUI, LangFlow, Flowise offer true infinite-canvas pan+zoom. LangSmith trees scroll-and-expand; Cursor Agents Window allows tile-drag and keybinding focus (most "spatial" non-graph nav). Devin panes resize and drag. No tool has named-viewpoints / bookmarks; LangSmith supports deep-link URLs per span.

### L4 — Level of Detail (LOD)

Trace UIs degrade poorly. ~10 spans = fine; ~100 = wall of indentation, users fall back on flame-graph (Langfuse) or filter-by-name; ~1 000+ = pagination or slowdown. Langfuse's "billions of observations" claim implies server-side aggregation, not per-trace LOD. ComfyUI's idiom is *collapse-to-subgraph* (group repeating motifs into one node); LangFlow's `component` abstraction is similar. Multi-pane workspaces LOD by hiding tiles behind tabs — binary expanded/collapsed. The only zoom-aware LOD is ComfyUI's third-party `MiniMap`.

### L5 — Anchoring (AR/VR-specific)

**N/A** across the catalog — every tool is desktop-web or terminal. No shipping visionOS / WebXR port as of May 2026. Closest implicit anchoring: Cursor persists tile arrangement across sessions.

### L6 — Labels & legends

Trace UIs use always-on span labels with duration pills; they become illegible past depth 6 (indentation eats horizontal space). Node-graphs show titles always-on, port names on hover/zoom-in. Chat tools embed labels in cards ("Thinking 12s", "Searched 4 sources"). No tool has voice-spoken labels; distance-thinning only via ComfyUI third-party plugins.

### L7 — Selection & group operations

- **Trace UIs:** click-a-span; weak group ops (filter/search across spans, no "re-run these 5"). Phoenix Playground partially fills this with replay.
- **Multi-pane:** single-tile focus only.
- **Node-graphs:** box-select, copy/paste, group-into-subgraph — best in the catalog.
- **Copilot Workspace + Cursor:** per-file checkbox selection in the plan or diff list — a *typed-set* model lifted from BI dashboards, applied to agent output.

### L8 — Attention flow

Dominant pattern: **streaming text + status pill**. Chat tools stream tokens; tool-call cards animate in; errors flip cards red — *push* signals, mild. Replit Agent 4 uses Trello-style column movement as the push signal. Cursor 3.1 adds per-tile completion badges + voice "thinking" indicator. Claude Code uses a status line footer + an Agent View column "is this session waiting on you?" — by far the cleanest *needs-input* signal in the catalog (everywhere else, the user must remember to check). Multi-agent breaks the chat-stream paradigm: Cursor `/multitask` users report missing completions because no global attention beam points at the latest change.

### L9 — Color system

- **Categorical** (operator kind): Langfuse / LangSmith color spans by `run_type` (LLM purple, chain blue, tool green, retriever yellow). ComfyUI colors nodes by category and wires by data-type.
- **Quantitative** (latency, cost, tokens): side-panel bar charts; Langfuse's flame-graph encodes duration in bar length, the only quantitative *intra-primitive* encoding.
- **State**: red error / yellow running / green success across the board. Replit Agent 4 uses kanban column position as primary state, color secondary.

Conflicts are mostly avoided by giving each encoding its own UI surface (color = kind, bar = quantity, position = state). Colorblind safety documented only in Langfuse and ComfyUI; the rest default to Material/Tailwind palettes that fail red-green.

### L10 — Inter-view linking

Mostly absent. LangSmith / Langfuse offer deep-link URLs but no "hover span → highlight source line." Phoenix's OpenInference / OTel semantic conventions enable cross-view brushing in principle (Datadog, Honeycomb). Cursor and Devin couple chat to editor — agent edits scroll the editor pane (basic linked highlighting). Copilot Workspace goes further: click a file in Plan → diff opens; edits flow back via *Update selected files*. ComfyUI/LangFlow's port-level "hover output → glow all connected inputs" is the strongest in-tool linking pattern.

### L11 — Process / reasoning representation (THE central question for WS-07)

This is where the catalog diverges most. Five archetypes emerge:

1. **Linear log with collapsible blocks** — ChatGPT, Claude chat. The reasoning is *temporally* ordered, *summarized* (o3 hides the raw CoT), and *collapsible*. User control is binary: open or closed. No way to mark a step as "wrong, retry from here."
2. **Hierarchical trace tree** — LangSmith, Langfuse, Phoenix, Helicone, Weave. The full structure of the reasoning is preserved as nested spans; the user can audit every step. But the tree is **post-hoc** — built after execution. Live updates exist (Langfuse) but are not the primary viewing mode.
3. **Plan + execution + verify pipeline** — Copilot Workspace, Devin Planner, Replit Agent task board. The reasoning is *projected forward* as a plan, then *executed* with progress per step. This is the most "spatial" non-graph representation — the plan is a vertical list, but each item has its own status, its own file list, its own diff. Closer to a Gantt-without-time view.
4. **Multi-pane "watch the agent work"** — Devin (full IDE replica), Cursor Agents Window, Bolt/v0/Lovable. The reasoning is *implicit in the artifacts being produced* — the user infers what the agent is "thinking" from what it just wrote/clicked. Lowest semantic content, highest concreteness.
5. **Node-graph DAG (authored, replayed)** — ComfyUI, LangFlow, Flowise. The pipeline *is* the reasoning. Execution lights nodes in topological order. This is the closest analog to a "spatial reasoning trace" — but only for pipelines that are pre-authored. No tool ships a node-graph that the agent itself constructs at runtime.

Always-on vs summoned: trace UIs are *summoned* (open the trace tab to see); chat UIs are *always on* (the thinking block is in the conversation); node-graphs are *the primary surface* (you cannot use ComfyUI without seeing the graph).

### L12 — Multi-user, sharing, persistence

- **Trace UIs:** team workspace + shared filter URLs + "Datasets" (pinned trace collections for evals). Persistence = cloud or self-hosted Postgres.
- **Chat UIs:** Claude/ChatGPT support shared links + Projects + Artifacts copies; no real-time editing.
- **Replit Agent 4:** explicit multi-user vibe-coding on the kanban board (2026 enterprise milestone).
- **Cursor:** worktrees / SSH per-agent sandbox; no in-chat collab.
- **ComfyUI:** workflow JSON + metadata-embedded PNGs — extremely portable, no collab.
- **Perplexity Spaces:** multi-user research stacks.

**Patterns visible in the matrix:**

- **Consumer chat tools hide cost/tokens** to reduce cognitive load — but this is exactly what advanced users need to inspect agent behavior. Jarvis, as a power-user tool, should default to *showing* cost.

- **Only Claude Code Agent View first-classes "waiting on you"** — a glaring gap. Most tools require the user to *poll* for completion.

## Reasoning trace spatial representations

How each tool *spatializes* (or fails to spatialize) reasoning — the WS-07 core question.

### Spatial-dimensionality scorecard

| Tool | Dimensionality | Primitive | Why it stops there |
|---|---|---|---|
| ChatGPT / Claude chat | 0.5D (scroll) | Stacked block | Linear narrative; collapse is the only spatial control |
| LangSmith / Langfuse / Phoenix tree | 1.5D (indented tree) | Span row | Indentation is cheap; works to ~50 spans |
| Langfuse flame-graph | 2D | Horizontal bar in vertical stack | Adds time-axis; ordering fixed by call order |
| Replit Agent 4 board | 1.5D | Kanban card | Column = state; intra-column position is not |
| Cursor Agents Window | 2D (tiles) | Pane | Each pane is 1D; user controls layout |
| Devin workspace | 2D (panes) | Role pane | Panes are roles, not reasoning steps |
| Copilot Workspace plan | 1D + diff drawer | Plan-item row | Plan order = execution order; no parallelism |
| ComfyUI / LangFlow node-graph | True 2D | Node + edge | Position carries authored meaning; runtime overlays light up |
| AutoGen Studio canvas | True 2D | Agent + edge | Agents are first-class graph nodes |
| Claude Code terminal | 0.5D + sidebar | TUI row | Terminal grid + Agent View table |

**The 3D gap.** Nothing in the catalog uses depth or volume for reasoning. Two structural reasons: (a) reasoning is naturally a DAG with a clear arrow of time, and 2D suffices (Sugiyama, dagre, ELK); (b) without AR/VR, the designer pays perceptual cost (occlusion, depth-of-field, orbit) for ambiguous benefit. ComfyUI tried 3D node previews and the community removed them.

**The Jarvis 3D opportunity.** Treat Z-axis as a *load-bearing* mapping:

- **Z = abstraction level** — top-level plan plates float forward; sub-agent traces nest behind, scaled smaller. Drill-in = camera dolly. Matches the existing Jarvis "drill into cluster" gesture.
- **Z = time/replay** — active step floats forward; completed steps sink back with opacity decay. Time-scrub = camera fly-back.
- **Z = agent identity** — each of {Worker, Layout, Listening, Naming} owns a parallel depth layer. Multi-agent work becomes spatially separable at a glance. Matches user mental model: agents as "different rooms."
- **Volume = reasoning thread** — translucent tube traced through space, tool calls as ports along it. Branches/retries become forked tubes — finally first-class.

### Spatial idioms worth lifting

- **ComfyUI "node lights up while executing"** — visual analog of a CPU instruction-pointer. Port: ghost-glow on the *plate currently being worked on*, with edge animation flowing forward.
- **Langfuse flame-graph** — port as a ribbon along the canvas floor showing per-agent wall-clock.
- **Cursor Agents Window tiles** — port as a per-agent dock-row, anchored bottom on desktop / hand-anchored palette in AR.
- **Copilot Workspace plan → diff coupling** — port as Jarvis *intent-ghost*: agent's draft plan becomes translucent ghost-plates *before* execution; user edits ghosts.
- **Anthropic Workbench prompt versioning** — port as *bookmark with diff*: same Layout-agent run, prompt A vs prompt B, side-by-side.

## Multi-agent representation

How parallel and sequential collaboration is shown:

| Tool | Parallel | Handoff | Shared context | Failure isolation |
|---|---|---|---|---|
| **AutoGen Studio** | Agents = canvas nodes; messages flow along edges; `GroupChat` node aggregates | Same canvas, edge direction | GroupChat memory node | Per-agent IO panels, error highlights |
| **MetaGPT** | Implicit role pipeline (PM → Architect → Engineer → QA); vertical role list w/ handoff arrows | Strongest sequential pattern | Shared documents (PRD, design.md) | Per-role logs |
| **CrewAI** | `Flow.plot()` hierarchical task tree | Flow edges | Crew + per-agent memory | Node failure highlight |
| **Devin** | Limited — one main agent + parallel browser tabs | Implicit via Planner | Shared VM workspace | Pane-level errors |
| **Cursor `/multitask`** | Explicit async subagent spawn, each gets a tile | Manual reassembly | Worktrees: separate filesystem branches | Per-tile red border |
| **Claude Code Agent View** | First-class dashboard of all sessions, state columns | User-driven | Per-session conversation; sub-agents share session ctx | Per-row status column |

**Three structural patterns:** (1) **Pipeline** (MetaGPT, CrewAI) — roles in sequence, doc per role; strong audit trail, weak parallelism. (2) **Free-for-all canvas** (AutoGen Studio) — agents as nodes; user designs topology; great for authoring, hard to follow at runtime with concurrent messages. (3) **Dashboard of independent sessions** (Cursor 3, Claude Code Agent View) — each agent owns its conversation, user orchestrates; scales to N agents but does not show *how they should coordinate*.

**For Interactive Jarvis** the dashboard-of-sessions pattern fits *operationally* (4 agents already have separate contexts); the canvas pattern fits *visually* (Jarvis is already artifacts-on-a-plane). The hybrid: **each agent owns a spatial region** (plane / cluster / depth-layer) on the same shared canvas; **handoff edges** appear when one agent's output feeds another. Layout already does this implicitly when it reorganizes after Worker output — surface the handoff *visually*.

## Top patterns extracted

1. **Collapsible thinking block** — ChatGPT o3, Claude chat, Claude Code TUI, ComfyUI subgraphs. Long-running state hidden behind a one-line summary. Works because power users want the chain, casuals want the answer. Caveat: binary open/closed loses partial-detail mid-state.
2. **Hierarchical trace tree** — LangSmith, Langfuse, Phoenix, Helicone, Weave. Parent → child indented spans, click to drill. Matches the call-stack mental model. Caveat: visually degrades past ~50 spans / depth > 6.
3. **Plan-then-execute stepper** — Copilot Workspace, Devin Planner, Replit Agent task board. Agent emits structured plan; user can edit before commit; execution ticks each item. Gives the user a contract. Caveat: bad plans are worse than no plan.
4. **Generate-then-preview split** — Bolt, v0, Lovable, Claude Artifacts. Chat left, live render right. Tight observe-modify loop. Caveat: needs an obvious render target.
5. **Tiled multi-agent grid** — Cursor 3 Agents Window, Devin panes, Claude Code Agent View. Each agent gets a pane. Separation of concerns. Caveat: no global attention beam.
6. **Status-column kanban** — Replit Agent 4, partially Claude Code Agent View. Cards move across columns as state changes; position *is* the state. Caveat: enforces one state machine.
7. **Citation footnotes + follow-up suggestions** — Perplexity. Inline numbered citations + Copilot sidebar with named next-steps. Makes the chain auditable and the conversation steerable. Caveat: footnotes noisy past 10 sources.
8. **Node-graph as authoring + trace** — ComfyUI, LangFlow, AutoGen Studio. The user-built graph IS the execution surface; runtime overlays light up active nodes. Zero translation cost. Caveat: agent must not decide topology at runtime.
9. **Worktree/sandbox per agent** — Cursor `/multitask`, Devin VM. Each agent gets isolated filesystem/browser/state. Failure containment. Caveat: hard state sync back to user.
10. **Side-by-side prompt-version diff** — Anthropic Workbench, Phoenix Playground. Two prompts, same input, scored. Shifts the model from absolute to relative quality. Caveat: needs a rubric.

## Anti-patterns observed

1. **Trace tree at depth 10+** — every observability tool breaks visually. Indentation eats horizontal space, labels truncate, expand-all is unusable.
2. **Hiding the reasoning entirely** — ChatGPT o1 originally hid raw CoT; users complained the model "felt unreliable" because they couldn't audit it. The summarized middle ground was a compromise, not the right answer for power users.
3. **Streaming chat as the primary multi-agent UI** — once N > 2 agents emit interleaved messages, the chat becomes unreadable. AutoGen Studio "profiler" view exists precisely because the chat view fails.
4. **Branch/retry loss** — every tool that traces reasoning *flattens* alternate attempts. The user never sees "the agent tried X, failed, retried Y." This is a systemic blind spot.
5. **Pane proliferation without attention** — Cursor users with 8 tiles open report missing completions. Tiles solve "where to look" only if you know which tile to look at; no tool has solved this.

## Implications for Interactive Jarvis

1. **`reasoning-thread` as first-class spatial primitive** — A volumetric tube (R3F `MeshLine`) traced from agent-origin → tool-call plates → result. Tool calls = beads; errors = red flares; branches = forked tubes. Replaces ActivityPanel scroll-list. Maps to **L11, L1**. Files: `renderer/src/scene/ReasoningThread.tsx` (new), `renderer/src/components/LayoutActivityPanel.tsx` (deprecate). Effort: **M**. AR-readiness: **+** (DOM ActivityPanel does not lift; tube does).

2. **Per-agent depth layer (Z = agent identity)** — Worker / Layout / Listening / Naming each own a parallel plane at `z = -k*agentIndex`. Plates start on producer's plane; cross-agent handoff edges become explicit. Maps to **L1, L11, L8**. Files: `electron/main/world-state.ts` (`producedBy: AgentKind`), `renderer/src/scene/AgentPlanes.tsx` (new), `renderer/src/scene/PlatesLayer.tsx`. Effort: **L**. AR-readiness: **+++** (anchored planes are native visionOS).

3. **"Waiting on you" attention beam** — On `awaiting_input` event, a 3D beam points from agent's plane to the plate that needs review; voice TTS announces. From Claude Code Agent View "waiting on you" column. Maps to **L8**. Files: `electron/main/agents/listening/index.ts`, `renderer/src/scene/AttentionBeam.tsx` (new). Effort: **S**. AR-readiness: **+**.

4. **Intent-ghost plates for plan-then-execute** — Before Layout reorganizes, render translucent ghost copies at proposed positions; user can drag-correct then commit. Lifts Copilot Workspace's "edit plan before implement" into 3D. Maps to **L11, L7**. Files: `electron/main/agents/layout/plan.ts` (return ghost-spec), `renderer/src/scene/IntentGhost.tsx` (new). Effort: **M**. AR-readiness: **+**.

5. **Branch-aware trace** — When an agent retries with different approach, both branches persist: A dim/translucent, B active. User can pin to compare. Closes the *retry-alternatives* gap seen across the catalog. Maps to **L11, L7, L10**. Files: `electron/main/world-state.ts` (add `branch`), `renderer/src/scene/BranchedThread.tsx`. Effort: **L**. AR-readiness: **neutral**.

6. **Per-agent cost/token HUD** — Floating widget on each agent's depth plane showing tokens / USD / current model. Always-on per L8 + power-user need. Maps to **L9, L2**. Files: `electron/main/agents/usage.ts`, `renderer/src/scene/AgentHUD.tsx`. Effort: **S**. AR-readiness: **+**.

7. **Workflow-as-DAG export** (ComfyUI-style) — On trace completion, offer "freeze as workflow" → editable node-graph re-runnable with different inputs. Bridges runtime trace → reusable pipeline (the convergent move from LangSmith and ComfyUI sides). Maps to **L11**. Files: `electron/main/mcp/workflow-tools.ts` (new). Effort: **L**. AR-readiness: **neutral** (2D editor first, lifts later).

## Open questions

1. **Live token streaming in 3D — perceptual cost?** Streaming tokens onto a plate in 3D may be visually noisy at distance. Does the spatial primitive degrade to a "typing dots" pulse beyond a threshold? Needs prototype.
2. **Branch comparison ergonomics** — How does a user *compare* two branches without losing context? Side-by-side requires duplicating the scene. Diff visualization in 3D is unexplored.
3. **Multi-agent message ordering** — When four agents emit overlapping text streams, what is the visual ordering policy? Time-axis ribbon? Per-agent lane? Color-coded scroll? Needs design exploration.
4. **Reasoning trace persistence at scale** — A long Jarvis session may produce thousands of spans. Does the scene LOD to "ribbon density" beyond N? What is the storage model — append-only event log, or compacted snapshots?
5. **AR voice + reasoning trace** — In visionOS, with gaze + pinch primary, does the trace need a "voice scrubber" ("Jarvis, take me back to the moment the Layout agent picked the wrong cluster")? Speech-driven temporal navigation is unexplored.
